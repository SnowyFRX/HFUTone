# HFUTone

校园课堂工具，把三件每天都在用的事收进一个窗口：

- **直播课堂** —— 课表、在线课堂直播画面、PPT 内嵌显示
- **长江雨课堂** —— 免扫码签到、看课件、随堂题
- **学习通** —— 五种签到自动/半自动处理；课程列表里没有的班，靠班级群的签到通知兜底

Windows 一个 `HFUTone.exe`，Android 一个 apk，两端共用同一套业务代码。

## 下载

到 [Releases](https://github.com/SnowyFRX/HFUTone/releases) 下最新版：

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows x64 | `HFUTone-1.4.5-win64.zip` | 解压到任意目录，双击 `HFUTone.exe`。免安装、无依赖 |
| Android | `HFUTone-1.4.5-release.apk` | 应用内版本 **1.4.5**（versionCode 25），支持 arm64 / x86_64，Android 7.0+ |

> 安卓装完请到「设置 → 应用 → HFUTone」确认版本是 **1.4.5**。显示的比这个旧，说明装的是旧包，卸载重装一次。

## 安装

**Windows**：解压 zip，把整个 `HFUTone` 文件夹放到一个**有写权限**的位置（别放 `C:\Program Files`），双击 `HFUTone.exe`。首次启动会在同目录建 `.config`，用来存登录态和设置。

**Android**：手机上打开 apk 安装。系统可能提示「已拒绝此应用获取敏感权限」——这是国产 ROM 对非应用商店来源包的默认限制，本应用只需要网络和前台服务，忽略即可。若提示「禁止安装未知来源应用」，在设置里给文件管理器授权一次。

## 第一次用

### 1. 直播课堂（桌面版）

启动后主区是直播课堂。首次使用点右上角「账号」填学号和统一身份认证密码，用于拉课表和取直播流。课表需要校园网或 VPN。

### 2. 雨课堂

顶栏「在线课堂」展开右侧栏 → 「雨课堂」tab → 点「App 登录」。

两种方式，各过一次人机验证：

| 方式 | 填什么 |
| --- | --- |
| 手机号 + 密码 | 雨课堂账号密码 |
| 手机号 + 短信验证码 | 点「发送验证码」→ 过验证 → 码到手后填进来 |

人机验证会嵌在弹层里打开。滑完自动回到填写表单，验证码那条会看到按钮变成「已发送 60s」。登录成功后标题右侧显示「App 身份」——**这个身份是动态二维码考勤免扫的前提**，没有它就只能手工扫码。

### 3. 学习通

同一个侧栏切到「学习通」tab → 「登录」→ 学习通手机号和密码（走网页登录口，和浏览器登录同一套）。

## 日常怎么用

### 雨课堂

- **刷新课程**：拉当前进行中的课堂
- **一键签到**：串行签所有未签的课，每节单独判定
- **看课件**：点课程行的「课件」，缩略图点开是单页大图，`←` `→` 翻页，`Esc` 退出
- **随堂题**：拉当前题目，填答案直接交；限时内通道被拒会自动走补交通道

没签到的行就写「未签到」。点「签到」后签上了会变成「已签到 刚刚」，没签上则直接写原因。

### 学习通

点「刷新签到」，只列**进行中且未签**的，每条标出类型和缺什么：

| 类型 | 能全自动 | 还缺 |
| --- | --- | --- |
| 普通签到 | 是 | — |
| 位置签到 | 是（坐标取自服务端下发的签到点；取不到才用设置里的） | 位置 |
| 手势签到 | 否 | 手势（九宫格数字，如 `12369`） |
| 签到码签到 | 否 | 签到码 |
| 二维码签到 | 是（自动读直播画面，或粘截图/链接） | — |

「一键签到」只签能全自动的那两种；缺输入的会跳过并在行上注明，点那一行的「签到」补上即可。

### 二维码签到：两种签到的路子完全不同

| | 雨课堂动态二维码考勤 | 学习通二维码签到 |
| --- | --- | --- |
| 主路径 | **不用扫码**。App 身份（App 登录拿到的那套凭据 + App 头）直接进班提交，码只是老师那边的呈现形式 | **只能把码本身拿到手**。没有免扫协议，必须解出二维码里的 `enc` 再提交 |
| 兜底 | App 身份不可用时，从正在播的课件画面截帧解码，当成"扫过的码"提交 | 从课件画面解码 / 把二维码截图粘进弹框 / 手机扫完粘链接 |
| 前提 | 登录过一次 App 身份 | 能看见那张码 |

- **雨课堂**：正常情况下你根本不用管二维码。App 登录成功后，动态码考勤就是一次普通提交；只有 App 身份不可用（没登、或登录成功但身份校验没过）才会退到"读画面里的码"这条路——那时才需要课件画面正在播。
- **学习通**：没有捷径，必须把码弄到手。三种来源任选：
  1. 桌面版开着课件画面时，程序会先自动从画面里读；
  2. 读不到就把二维码**截图粘进弹框**（`Ctrl+V` 或把图片拖进去），程序本地解码，不用联网认图；
  3. 手机扫完，把链接粘进去。
- **其他学校 / 没有本校直播源**：第 1 条用不上（没有画面可读），第 2、3 条照常——截图和扫码都不依赖直播平台。
- **Android**：手机上不跑直播画面，所以第 1 条没有；用截屏后粘贴到签到弹框，或直接粘扫码链接。

### 课程列表里没有的班：靠班级群

学习通的课程列表来自「课程中心」，有些班不在里面（教务后台直接排的、老师临时开的）。
这类课现在有两条路，优先第一条：

1. **班级群的签到通知**（自动）：打开学习通面板后，程序会连一次学习通的即时通信服务，
   把这个账号所在各群的签到消息读进来——包括最近的历史消息和之后老师新发的。
   这些活动会直接并进同一个签到列表，行上标「来自班级群」，点「签到」的流程和其它签到完全一样。
   程序关掉期间错过的消息，下次连接时会补回来。
2. **手写配置**（兜底）：界面上没有加课入口，得编辑 `HFUTone\.config\settings.json`
   里的 `cx.extraCourses`，格式见下方常见问题。

课程中心里那些「还没激活」的班，现在也一并扫（真实账号上 27 门课里有 14 门是这种状态，
以前会被整个过滤掉，于是老师发了签到也扫不到）。

**位置签到**：雨课堂那边坐标由服务端下发，不需要你做任何事；学习通那边如果服务端没给点，
才用「设置 → 学习通位置签到坐标」里填的地址 + 经纬度。

### 自动化：自动刷新与自动签到

| 项 | 桌面版 | 安卓版 |
| --- | --- | --- |
| 自动刷新签到 | 支持，默认开，每 60 秒扫一次（扫完再排下一轮） | 同左（页面不可见时跳过） |
| 自动签到 | 支持，默认**关**（设置里勾选） | 同左（后端守护线程，依赖前台服务保活） |

勾上「自动签到」后由后端守护线程执行：学习通走 IM 秒签，低频轮询兜底；雨课堂
后台监测进行中的课堂。IM 长连接跑在 Python 后端，掉线时轮询自动收紧到 45 秒。
需要人补输入的（手势、签到码、要验证码）不会硬试，只记一条「需人工」并留在列表里等你点。

安卓端是同一套后端引擎，随 `KeepAliveService` 前台服务常驻；进程被系统回收后
`START_STICKY` 会把它拉起来。

### 设置项

设置面板分三档，按用途分开（安卓上没有「直播」这一档，整块撤掉）：

**直播**（仅桌面）

| 项 | 默认 | 作用 |
| --- | --- | --- |
| 课程开播时自动接画面 | 开 | 程序在线时每 12 秒检查有没有课开播，一开播自动接上 |
| PPT 独立窗口 | 关 | 勾上再单开一个播放器窗口（等于三路全开） |
| 老师流 / 学生流 | 开 / 关 | 单独开播放器窗口；学生流无音频，默认关 |

**签到**

| 项 | 默认 | 作用 |
| --- | --- | --- |
| 学习通位置签到坐标 | 空 | 位置签到用。地址描述就是你让老师看到的那句话，别随手填 |
| 雨课堂自动签到 | 关 | 后台监测进行中课堂并免扫签到 |
| 自动刷新签到 | 开 | 前端列表定时刷新（60 秒一轮） |
| 学习通自动签到 | 关 | IM 秒签 + 低频轮询兜底 |
| 低频兜底轮询间隔 | 180 秒 | 60~600。IM 在线时按它走，掉线自动降到 45 秒 |
| Webhook 推送地址 | 空 | 钉钉/企微/飞书/Server酱/PushPlus/Bark/通用 JSON |

**其他**

| 项 | 作用 |
| --- | --- |
| 后台保活（关闭电池优化） | 安卓专用，跳系统设置把本应用排除出省电策略 |
| 关于 / 检查更新 | 对比最新版本，详见下一节 |

### 检查更新

设置 →「其他」→「关于」里有「检查更新」。读的是仓库里的公开 `web/version.json`，
三道源依次尝试：jsDelivr（主）、GitHub raw、GitHub API（兜底）。**不依赖任何自建服务器**，
三道全挂只显示「检查失败」，不影响任何功能。结果缓存 6 小时；有新版会给 Release 链接，
点「去下载」交给系统浏览器。

安卓顶栏还有一个「说明」按钮，把和桌面版的差异、电池优化、人工环节这些一次性讲清楚。

小字看不清时**点一下直播画面**就铺满窗口，`Esc` 退回。侧栏宽度可以拖左边那条竖线调整。

## 常见问题

**装上图标还是那个安卓小机器人 / 版本显示 1.1？**
装的是旧包。先卸载再安装 Release 里的最新 apk，应用信息里应显示 1.4.5。

**人机验证滑完了窗口不回去？**
1.1.1 起已修（现在发码按钮还会显示「已发送 60s」）。更早的版本会卡在验证页，只能点「回窗口」手动退出。

**点了签到，状态还是「已进班 · 待签到」？**
说明老师还没发起考勤。顶栏红点会留着，等老师发起后再点一次「一键签到」。

**位置签到提示「缺位置」？**
去设置里填坐标。经纬度在高德/百度地图上长按地点就能复制。

**直播画面是黑的 / 只有一小块？**
画面由程序内部解码后逐帧绘制，不是网页直接播视频。先确认这堂课老师确实在推流；课表需要校园网。侧栏宽度有限，画面按等比缩小显示，想看大字点一下放大。

**重装 / 换电脑登录态会丢吗？**
会。登录态和设置都在 `HFUTone\.config\` 里。想保留就先备份这个目录，装好新版本再拷回去。重新打包程序不会清空它。

**老师临时建的课扫不到签到？**
先看「群聊签到」——打开学习通面板后程序会自动读班级群里的签到通知，这类班通常都在群里。
如果群里也没有（比如不是用群发通知的），再手动把课程信息写进配置：编辑 `HFUTone\.config\settings.json`，在 `cx.extraCourses` 里加一条

```json
{
  "courseId": "课程ID",
  "classId": "班级ID",
  "cpi": "",
  "name": "课程名"
}
```

`courseId` 和 `classId` 在老师发的班级邀请链接里（`...phone/toParticipateCls?inviteCode=...&classId=...`）；用那个链接请求一次，返回页面里有 `courseId`。改完重启程序生效。

## 已知限制

- **学习通扫码登录没有界面**：只支持手机号 + 密码。
- **强制人脸用账号里已有的历史人脸**：`getUserFaceid` 取那张图，改几个字节重传换新 objectId，
  再换活动级 `faceEnc`。`openCheckFaceFlag=1` 的活动会自动带上，被判「签到环境异常」时去掉人脸重交一次。
  账号没有历史人脸就签不上。
- **滑块验证码自动识别缺口**：`showVCode=1` 的活动先弹滑块，程序算缺口、摆位、提交，
  拿到 `validate` 后继续签到。识别不可信时不提交，说明原因并退回手动拖。取图和提交都走本地代理。
  缺口判定用白化模型：拼图是 56×160 竖条，形状只占一段，y 与缺口同源，只搜 x；真缺口是原像素按
  α≈0.28 混白，拟合 `B = α·255 + (1-α)·S` 取残差最小。α 超出 0.18~0.42 或最优/次优分离度不足 1.05
  就判不可信。
- **验证码要人滑**：服务端要求时会出现「缺验证码」，点签到手动填。
- **雨课堂动态码走 App 身份免扫**，没在真实课程上长期验证过；失败时才会退到读画面里的码。
- **群聊签到依赖学习通的即时通信服务**：长连接跑在 Python 后端（`src/cxim.py`），不依赖页面打开；进程被系统杀掉才会断，重连后靠漫游消息补。
- **Android 版没有直播画面**：课表与直播需要校园网和播放器，手机上只保留签到相关功能。

## 数据与隐私

- 凭据和设置只存在本机 `.config` 目录（cookie、坐标、已签到记录、日志）。
- **不会把账号密码发到任何我们自己的服务器**——这个项目没有服务端。
- 群聊签到需要连一条第三方长连接：学习通把群消息托管在环信（北京易掌云峰）上，程序和
  学习通官方客户端连的是同一个服务。这条连接只做一件事——读这个账号所在班级群的签到通知；
  除它以外不往任何外部服务器发东西。若不想用这条，忽略「群聊签到」即可，其他功能照常。
- 发布包内不含任何人的配置：仓库里有 `tools/release_check.py` 扫描路径 / 标记 / 明文三层，命中就拒绝发布。
- 日志在 `.config/logs/`，只记接口调用结果，可随时删除。

## 从源码运行 / 自行编译

```bat
python app_qt.pyw            :: 直接跑源码
python build.py              :: 打包，产物 dist\HFUTone\HFUTone.exe
```

打包**必须**用 `build.py`，它会在打包前备份、打包后还原 `.config`，直接跑 PyInstaller 会清空登录态。

安卓：

```bash
export JAVA_HOME="/path/to/android-studio/jbr"
export ANDROID_HOME="/path/to/Android/Sdk"
gradle -p android assembleRelease
# 产物 android/app/build/outputs/apk/release/app-release.apk
```

业务代码只有一份（`src/` + `web/`），两端共用；安卓在构建时自动把 `web/` 复制进 assets，不需要手动同步。更细的开发约定见 [AGENTS.md](AGENTS.md)。
