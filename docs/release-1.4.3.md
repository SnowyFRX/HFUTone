## 新功能

### 滑块验证码自动识别（学习通）

`showVCode=1` 的签到不再需要人工拖滑块：取图后自动算缺口、摆位、提交，换到
`validate` 后继续签到；识别不可信时明说原因并退回人工拖。

之前两次尝试（模板匹配 / 遮罩亮度）都失败，是因为两张图的结构判断错了：

- `cutoutImage` 是 **56×160 的整条竖条**，真形状只占其中一段（48–52 × 47–55），
  其余全透明，且它的 y 与缺口在背景里的 y 同源 —— 拿整条去 `matchTemplate`，
  一百多行透明像素把相关性稀释掉了；
- 背景上其实有**两个**形状：一个深灰不透明的干扰块，一个白色半透明的真缺口；
- 真缺口是「原像素按 α≈0.28 混白」，不是暗阴影，所以亮度阈值必然被白狗、白云、
  亮草地这类本来就白的东西骗走。

现在的做法：从 alpha 取形状 bbox，y 直接用，只一维搜 x；拟合
`B = α·255 + (1−α)·S` 的残差。门控 `α∈(0.18,0.42)` 且最优/次优分离度 ≥ 1.05，
不满足就退回人工。识别在前端（`web/cxgap.js`）——安卓的 chaquopy 只带标准库，
浏览器是两端唯一都有 JPEG/PNG 解码器的地方。

实测：8 张真实样本定位全对，两张该退回人工的被门控挡住；真实提交 5/5 换到
`validate`；浏览器内合成图（带灰干扰块 + 平坦纯白区）精确命中。

### 后端自动签到引擎（#1，by First_QB）

`src/autosign.py`，桌面与 Android 共用同一套调度：

- **学习通**：环信 IM 实时群消息入队秒签；低频全量轮询兜底（默认 180s + 随机抖动，
  可设 60–600s）；
- **雨课堂**：后台监测进行中课堂并免扫签到，`joined`（已进班待签到）状态 45s 冷却复查；
- 失败重试最多 3 次，退避 60/180/600s；
- **不绕过人工环节**：要验证码 / 手势 / 签到码 / 无画面二维码 / 未配坐标的，只记一条
  `need_action`，交给状态面板和可选 Webhook 提醒；
- 面板：自动签到守护状态 + 事件流水；Webhook 支持钉钉、企业微信、飞书（含 Lark）、
  Server 酱、pushplus、Bark；
- 新增设置 `ykt.autoSign`（雨课堂自动签到，默认关）、`cx.autoSign`（默认关）、
  `autoSign.pollIntervalSec`、`autoSign.webhookUrl`。

> 自动签到默认**关**，要在设置里手动打开。安卓端依赖既有 `KeepAliveService`
> 常驻前台服务，进程被系统回收后 `START_STICKY` 拉起继续跑。

## 修复

### 强制人脸三环（`openCheckFaceFlag=1`）

早先实测「带人脸反而被判『签到环境异常』」，据此把人脸改成默认不带。症状没错，
根因错了 —— 底下压着三个 bug，叠起来的效果是「上传从来没成功，faceId 永远是
历史那一个」：

1. 历史人脸图床 `p.ananas.chaoxing.com` 对 `http://` 一律 301 到 https，
   下载没跟随重定向 → 空 body → 直接返回原 objectId；
2. 上传的 multipart 被 App 头里固定的 `application/x-www-form-urlencoded` 盖掉了
   curl 生成的 boundary → 服务端按 urlencoded 解析 → 字段全 null
   （`{"code":-5,"msg":"参数错误, puid不能为空, null"}`）；
3. 就算传上去，文件字节没变 → `crcStorageStatus` 命中 → 服务端把同一个 objectId
   原样还回来，等于没换脸。

修完实测：原图上传回来的仍是历史 objectId，追加两个字节上传就拿到新的；
`face_enc` 对真实活动返回 `status:1` 和真 `enc`。

策略改回：`needFace` 的活动自动带人脸，且只在**位置签到/二维码签到**两类带
（`course_helper` 的普通签到也不带）；真撞上「环境异常」去掉人脸重交一次兜底。

## 已知限制

- **验证码 / 手势 / 签到码不硬猜**：自动签到碰到这些只记录 `need_action`，仍需人工；
- **位置签到需要先配坐标**，没配的不会进自动队列；
- **群聊签到依赖程序开着**（IM 连接由前端 SDK 维持），关掉期间的靠下次漫游消息补；
- **雨课堂没有「自动刷新」开关**：前端 15s、后端 25s 恒定轮询；自动签到开关是这次
  新加的 `ykt.autoSign`，默认关。
