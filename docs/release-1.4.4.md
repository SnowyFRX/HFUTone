# HFUTone 1.4.4

基于 `1.4.3` 的实测反馈集中修复与性能优化，覆盖学习通扫描速度、多步签到、二维码图片解码、自动签到守护交互与桌面布局。

> 附件文件名沿用 `HFUTone-1.1-win64.zip` 以保持 README 下载链接兼容；Windows 桌面版已内置本次全部修复与 OpenCV 二维码解码器。Android 代码已同步入库，APK 待维护者签名构建。

## 性能优化

### 学习通扫描提速（`src/cxapi.py` / `src/cxsign.py` / `web/im.js`）
- **缓存入班时间**：`join_class_time()` 写入内存与 `.config/cx.json`，不再在每次扫描时对每门课重复查 `/gas/clazzperson`（减少约 1/3 请求）。
- **按需查第二路活动列表 & 复用预检**：`taskactivelist` 未发现窗口内签到时跳过 `/v2/apis/active/student/activelist`；`_describe()` 直接复用已获取的 `attend_info`。
- **群聊历史活动并发预检 + 过期缓存**：群聊签到改为 8 线程并发预检（课程扫描提至 10 线程），已确认过期或已签的历史活动记入 `_dead_chat_ids`，后续扫描不再重复查询且不回落到必 404 的 REST 接口。
- **环信漫游批量上报**：各群漫游消息拉取完成后合并为单次上报，避免每个群拉完都触发全量刷新。

## 修复与体验改进

### 手势 / 签到码 + 验证码与位置范围限制（`web/cx.js` / `src/cxsign.py`）
- **修复多步签到参数丢失死循环**：原 `signOne` 在验证码与手势/签到码回调中各自构造新 `extra` 对象导致参数互盖、来回弹窗；现通过 `mergeExtra` 保留所有已输入字段，且同时需要手势/签到码与验证码时先填码再过滑块。
- **兼容 `errorLocation2_<米数>` 三点定位反推**：带位置范围限制的手势/签到码超距时服务端返回 `errorLocation2_885.0` 而非中文文案；现已将两轮三点定位抽成公共方法 `_calibrate_by_distance`，位置/手势/签到码均可自动校准签到点。
- **修复三点定位直接命中却误报失败**：探测点直接返回 `success` /「已签到」时立即判定成功并结束，不再二次提交换来「您已签到过了」。

### 自动签到守护交互与桌面布局（`src/autosign.py` / `web/server.py` / `web/index.html` / `web/ppt.js` / `web/ykt.css`）
- **已签状态即时同步**：手动签到成功或后续扫描确认已签后，`mark_resolved()` / `sync_cx_signs()` 实时将对应的「需人工」记录翻为已签并清零待人工计数。
- **遇到验证码主动弹出人工验证框 & 卡片直达入口**：开启自动签到且窗口在前台时，遇到带验证码的活动主动弹出滑动验证窗口；待人工记录上提供直接的「去验证 / 手动签到」快捷入口。
- **单行紧凑状态条 + 手动签到列表自适应**：移除与「刷新签到」重复的「立即检查」按钮，默认折叠自动签到守护为单行状态条（「记录 ▾」按需展开）；侧栏手动签到列表改为 `height: auto` 自适应撑开，不再内部上下滚动。
- **签到成功 0 延迟更新界面**：`signOne` / `signAll` 成功后立即就地刷新列表条目，再用轻量 `refresh()` 同步快照，消除此前等待十余秒全量扫描才移除未签条目的延迟。

### 二维码图片粘贴解码增强（`src/yktqr.py` / `web/server.py`）
- 自动补静区白边（quiet zone）+ 多尺度缩放 + Otsu/自适应二值化，提升紧贴边缘或低对比度截图的二维码识别率；缺少 `cv2` 解码库时给出明确错误提示。
