# HFUTone 1.4.5

versionCode **25**

这一版没有改签到链路，集中在三件事：能自己检查更新、设置不再一坨、安卓端把限制讲清楚。

## 检查更新

设置 →「其他」→「关于」里有「检查更新」。读的是仓库里公开的 `web/version.json`，
三道源依次尝试：

```
cdn.jsdelivr.net   ← 主路，公共 CDN，国内可达、没有限额
raw.githubusercontent.com
api.github.com     ← 兜底，匿名只有 60 次/小时/IP，校园网 NAT 后面撑不住
```

**不依赖任何自建服务器**。三道全挂只显示「检查失败」，不弹窗、不阻断任何功能。
结果缓存 6 小时，手动点按钮才绕过。有新版给出 Release 链接，点「去下载」交给系统浏览器。

`web/version.json` 的版本号由 `build.py` 每次打包从 `build.gradle` 同步，不会再出现
两处版本对不上的情况。

## 设置分了三档

原来 7 组堆在一起，现在顶部有胶囊导航：

- **直播**（仅桌面）：自动推流、PPT 独立窗口 / 老师流 / 学生流
- **签到**（默认）：位置签到坐标、雨课堂自动签到、学习通自动刷新 / 自动签到、轮询间隔与 Webhook
- **其他**：后台保活、关于

切档时内容淡入并轻微上浮，不再是硬切。窄屏自动退回单列。

## 安卓端

**电池白名单引导**：首次冷启动弹自家的对话框，说清楚「系统会在息屏后清掉后台，
签到守护会静默停止」，点「去设置」才跳系统对话框；被拒后不再打扰。
设置里另有常驻的手动入口（「后台保活 → 关闭电池优化」）。

**说明弹层**：顶栏新增「说明」，一次讲清和桌面版的差异、必须知道的四件事、
以及凭据存放位置。内容可维护——它来自仓库里的一份 txt 草稿。

## 交互细节

- 触屏点击不再出现系统那层蓝色方块（`-webkit-tap-highlight-color`）；
- 按钮补了过渡和按压反馈，触屏上不再出现「点完还保持着 hover」；
- 随堂题卡片的题号缩成后 6 位，倒计时和提交按钮不再被挤出去；
- 说明弹层能滚了（`.sheet-wide` 的 `overflow: hidden` 之前把内容裁掉了）。

## 已知限制

- 验证码 / 手势 / 签到码 / 二维码 / 没配坐标的位置签到，只记「需人工」，不会硬交。
- 雨课堂动态码在手机上没有课件画面可截，只能落到「需人工扫码」。
- 自动签到默认**关**，要在设置里手动打开。
- 安卓的守护进程靠前台服务维持，被系统回收就停；请把本应用排除出电池优化。
