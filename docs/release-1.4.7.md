# HFUTone 1.4.7

versionCode **27**

修 1.4.6 里更新检测的三个毛病，签到链路没动。

## 修了什么

- **红点飞了**：`.badge` 是绝对定位，父按钮没有定位上下文，于是挂到了顶栏右上角。
  现在固定在「设置」按钮上。
- **按钮被收走**：查到新版就把「检查更新」藏起来，现在一直留着，随时能再查。
- **误报旧版本**：装上新版之后，本地缓存里还写着旧的 `current`，于是 1.4.6 上会提示
  「v1.4.5 可用」。缓存现在必须和当前安装的版本对得上才使用，否则重新查。

顺带：手动检查到「已是最新」会把顶栏红点撤掉。

## 已知限制

- 验证码 / 手势 / 签到码 / 二维码 / 没配坐标的位置签到，只记「需人工」。
- 自动签到默认**关**。
- 安卓守护进程靠前台服务维持，建议排除出电池优化。
