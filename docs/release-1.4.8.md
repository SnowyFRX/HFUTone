# HFUTone 1.4.8

versionCode **28**

只换更新检测的主源，签到链路没动。

## 为什么

1.4.6/1.4.7 发出去之后实测发现：jsDelivr 的 `@main` 路径有 **12 小时缓存**，
发版后半小时内它还返回旧版本，`purge` 也只能一层一层往前推（1.4.5 → 1.4.6），
等不到 1.4.7。

换成 `@latest`——它解析到最新的 tag，**打完 tag 立即可读**。实测同一时刻：

```
@latest        → 1.4.8
@main          → 1.4.6   （滞后）
releases.atom  → 1.4.8
```

所以现在的顺序是 `@latest` → `@main`（兜底）→ atom，仍然取三路里最高的版本。
