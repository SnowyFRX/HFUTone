# HFUTone 1.4.9

versionCode **29**

## 课件不再重复拉取

同一个课堂第二次点「看课件」，现在直接用缓存，不再走一遍网关取 `presentation_id`、
再拉几十页的元数据。课件页在一次课堂里是静态的，图片地址不会变。

- 右上角新增 **↻**，老师换了课件时手动重拉；
- 缓存挂在课堂对象上，切换课堂各自独立；
- 【题目】弹层与课件弹层共用同一份缓存，点过一边另一边就有了。

## README 补了取码机制说明

新增「从课件画面取码是怎么工作的」：底层 20fps 抽帧是为了显示画面，找码是**按需**
抓最多 4 帧（约 2.4 秒），不是常驻任务；只解当前画面，不翻页。

## 已知限制

- 验证码 / 手势 / 签到码 / 二维码 / 没配坐标的位置签到，只记「需人工」。
- 自动签到默认**关**。
