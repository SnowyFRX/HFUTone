# HFUTone 1.4.9

versionCode **29**

## 过期二维码也能签了

学习通签到接口只认链接里的 `enc`，`c`（signCode）只是老师屏幕上的展示码。
展示码轮换了 `enc` 照样有效，所以过期的码也能提交成功。

之前 `parse_qr` 拿 `c` 去和 `signDetail` 返回的 `signCode` 比，对不上就返回
「二维码已过期」——把本来能签的路堵死了。现在只标记、不拦截，提交时提示一句
「展示码已过期，但 enc 仍有效」，照常签。

手里只有二维码截图时，可以在「二维码」输入框提示的帮助下先到
[cli.im/deqr](https://cli.im/deqr) 解成链接再粘进来。

## 课件不再重复拉取

同一个课堂第二次点「看课件」直接用缓存，不再走一遍网关取 `presentation_id`。
右上角新增 **↻** 手动重拉；缓存挂在课堂对象上，切换课堂各自独立；
【题目】弹层与课件弹层共用同一份缓存。

## README 补了取码机制说明

新增「从课件画面取码是怎么工作的」：底层 20fps 抽帧是为了显示画面，找码是
**按需**抓最多 4 帧（约 2.4 秒），不是常驻任务；只解当前画面，不翻页。

## 已知限制

- 人机验证码 / 手势 / 签到码 / 没配坐标的位置签到，只记「需人工」。
- 二维码签到例外：给二维码或链接即可，过期的也行。
- 自动签到默认**关**。
- 安卓守护进程靠前台服务维持，建议排除出电池优化。
