# HFUTone 1.5.1

versionCode **31**

## 签到守护搬进通知栏

后台时不再是干巴巴一行「守护中」，而是一条胶囊（RemoteViews 自定义布局）：

- 左侧状态点：绿＝IM 长连接在线，红＝掉线重连中，灰＝自动签到没开；
- 主行「签到守护中」，副行「学习通 开 · 雨课堂 开 · IM 在线」，掉线时变成
  「IM 重连 · 兜底 45s」；
- 右侧等宽字体显示「已签 3」或「2 待办」；
- 每 5 秒跟一次状态，点它回到 App。

## 签到成功会弹横幅

后台自动签掉一条，立刻弹一条 heads-up 横幅：左边亮绿竖条、粗体「已自动签到」、
下面一行课程与签到名、右侧时间。和胶囊同一套深底圆角视觉。

冷启动只记事件起点，不会把历史签到刷屏。

## 补了通知权限

Android 13 起通知是运行时权限，之前没申请——常驻通知和横幅都不会显示。
现在首次启动会申请 `POST_NOTIFICATIONS`。

## 一并带上的近期改动

- **学习通扫码登录**（1.4.10）：登录弹层双 tab，扫完自动关闭并刷新；
- 扫码登录不再抹掉已有 IM 账号（这个 bug 会让群聊秒签静默失效）；
- 课件页按 `lessonId` 缓存，关掉再开不再重新拉；
- 过期二维码也能签（签到接口只认 `enc`，展示码过期不影响）；
- 检查更新：启动静默查，有新版在「设置」上挂红点。

## 已知限制

- 人机验证码 / 手势 / 签到码 / 没配坐标的位置签到，只记「需人工」。
- 二维码签到例外：给二维码或链接即可，过期的也行。
- 自动签到默认**关**。
- 安卓守护进程靠前台服务维持，建议排除出电池优化；通知权限也要允许，否则胶囊和横幅都看不到。
- 个别国产 ROM 会拦自定义通知布局，届时退回系统默认样式。
